# Vérification du projet Messay API

Projet réalisé dans un cadre professionnel soumis à accord de confidentialité.

## Méthodes de vérification
- Explication détaillée des choix d'architecture backend et de modélisation en entretien
- Revue des principes de sécurité appliqués (Sanctum, validation, transactions financières)
- Démonstration fonctionnelle des endpoints API si autorisée
- Cohérence avec les compétences et technologies listées
